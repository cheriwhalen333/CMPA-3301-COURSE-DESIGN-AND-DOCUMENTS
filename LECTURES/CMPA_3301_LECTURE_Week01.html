🎯 The "Why"

Documentation is the project. As a Hybrid Project Manager, you manage the product and the knowledge surrounding it.

Why Markdown? Markdown allows you to write content that is clean, portable, and developer-friendly. It separates your writing (content) from your formatting (presentation), which is exactly how modern web documentation works.

Why GitHub? Learning GitHub in a college environment is a rare privilege. You are getting access to the industry-standard version control system now, which gives you a significant head start over your peers in the job market. You are learning to track your work, collaborate, and version your projects like a professional engineer.

🔧 The "How" (Markdown Mastery)

When creating your charter.md, syntax is everything. Observe these differences:

❌ Incorrect Markdown

#Header1 (Missing space)
(BoldText) (Wrong symbols)
[Italic] (Wrong symbols)
+ Item (Inconsistent)
==Header 2== (Invalid)
# Name
Goals:
1. Learn (Missing spacing)

✅ Correct Markdown

# Name (Space included)
## Course Goals
1. Learn GitHub.
2. Master Markdown.
## Potential Challenges
- Balancing course load.
- Git commands.
[Link](https://github.com/...)
